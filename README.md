# photoshop-Fofl76

Веб-приложение для работы с изображениями: каналы, уровни, масштабирование с собственной реализацией интерполяции (ближайший сосед и билинейная).

## Демо

Статическая сборка развёрнута на Netlify:

**https://delicate-sfogliatella-2dd53a.netlify.app**

## Локальный запуск

```bash
npm install
npm run dev
```

Сборка для продакшена:

```bash
npm run build
```

## Масштабирование

- **Панель состояния** — масштаб отображения на холсте 12%–300% (ползунок и пресеты).
- **Инструмент «Изменение размера»** — модальное окно для изменения размеров изображения в пикселях или процентах с выбором алгоритма интерполяции.
- При загрузке изображение автоматически вписывается в холст с отступом не менее 50 px.

Интерполяция реализована в `src/core/image/interpolation/`.
